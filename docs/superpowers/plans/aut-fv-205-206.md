> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automate guest voucher redemption and order-summary validation through direct product purchase for AUT-FV-205 and AUT-FV-206.

**Architecture:** Google Sheets remains the source of truth. One guest `ProductPurchasePage` owns direct product navigation, purchase selection, voucher entry, errors, and summary reads; one Buyer promotions spec contains exactly one test per Automation ID.

**Tech Stack:** TypeScript, Playwright, Google Sheets connector, existing Yapp fixtures and utilities.

- Do not log in, open the cart, select payment, create a transaction, or call an application API.
- Use `Telebot` option `plan b` for eligible promotion cases and `Test Discounted Product` by `geri` for product-ineligible validation.
- Keep one test for `@AUT-FV-205` and one test for `@AUT-FV-206`.
- Keep mutable product and promotion fixtures in one Buyer promotion data file.
- Run only the mapped promotion test being developed.
- Keep both mapping statuses `Planned` until their isolated Playwright tests pass.
- Preserve Sheet formatting, formulas, validation, and unrelated cells.

- [ ] **Step 4: Add the minimum page-object contract and fixture**

Create `src/pages/buyer/ProductPurchasePage.ts` with this public contract:

```typescript
import { expect, type Locator, type Page } from '@playwright/test';
import { safeClick, safeFill, waitForLoaded } from '@utils/playwright.utils';
import type { PurchaseProduct } from '@test-data/buyer/promotion.data';

export type OrderSummary = {
  subtotal: number;
  discount: number;
  total: number;
};

export class ProductPurchasePage {
  readonly voucherInput: Locator;
  readonly applyVoucherButton: Locator;

  constructor(public readonly page: Page, private readonly baseURL: string) {
    this.voucherInput = page.getByRole('textbox', { name: 'Redeem Voucher' });
    this.applyVoucherButton = page.getByRole('button', { name: 'Apply' });
  }

  async goto(product: PurchaseProduct) {
    await this.page.goto(new URL(product.path.slice(1), this.baseURL).toString());
    await waitForLoaded(this.page);
  }

  async expectLoaded(product: PurchaseProduct) {
    await expect(this.page).toHaveURL(new URL(product.path.slice(1), this.baseURL).toString());
    await expect(this.page.getByText(product.title, { exact: true })).toBeVisible();
  }

  async openPurchase(product: PurchaseProduct) {
    await this.goto(product);
    await this.expectLoaded(product);
    if (product.option) {
      const optionCard = this.page.getByText(product.option, { exact: true }).locator('..');
      await safeClick(optionCard.getByRole('button', { name: 'Select', exact: true }));
    } else {
      await safeClick(this.page.getByRole('button', { name: 'Purchase', exact: true }));
    }
    await expect(this.voucherInput).toBeVisible();
  }

  async applyPromotion(code: string) {
    await safeFill(this.voucherInput, code);
    await safeClick(this.applyVoucherButton);
  }

  async getOrderSummary(): Promise<OrderSummary> {
    return {
      subtotal: await this.readMoney('Subtotal'),
      discount: await this.readMoney('Discount'),
      total: await this.readMoney('Total'),
    };
  }

  async expectActiveDiscount(before: OrderSummary, percent: number) {
    await expect.poll(() => this.getOrderSummary()).not.toEqual(before);
    const after = await this.getOrderSummary();
    expect(after.subtotal).toBe(before.subtotal);
    expect(after.discount).toBeCloseTo((before.subtotal * percent) / 100, 0);
    expect(before.total - after.total).toBeCloseTo(after.discount, 0);
  }

  async expectRejectedPromotion(before: OrderSummary, error?: string) {
    const message = error
      ? this.page.getByText(error, { exact: true })
      : this.page.getByText(/invalid|expired|maximum|limit|promo/i);
    await expect(message).toBeVisible();
    expect(await this.getOrderSummary()).toEqual(before);
  }

  private async readMoney(label: string): Promise<number> {
    const row = this.page.getByText(label, { exact: true }).locator('..');
    const text = await row.innerText();
    const value = text.match(/-?\s*Rp\s*([\d.]+)/i)?.[1];
    expect(value, `${label} must contain an IDR amount`).toBeTruthy();
    return Number(value!.replaceAll('.', ''));
  }
}
```
